\begin{abstract}
\vspace{1cm}

Memory Protection Unit (MPU) implementation is critical for automotive ECUs to meet ISO 26262 safety standards, but performance implications remain poorly understood. This thesis presents experimental performance analysis of MPU-enabled systems using ARM Cortex-M4 STM32F446 with cycle-accurate measurements.

\keyresult{Experimental results reveal MPU region allocation overhead of 990 ± 4 cycles (5.500 ± 0.022 μs) for protected IPC applications versus 130 ± 2 cycles (0.722 ± 0.011 μs) for baseline applications.} This represents a 7.6× performance factor with deterministic, predictable timing suitable for automotive real-time systems.

\measurement{For typical automotive systems with 2 MPU-protected tasks, total overhead is 1980 cycles (11.0 μs)}, resulting in <1\% impact on engine control systems and <0.1\% impact on chassis control systems. The one-time initialization overhead is 10-20× lower than software protection alternatives while providing hardware-enforced security.

Results validate practical feasibility for production automotive systems. \keyresult{MPU protection overhead remains within real-time constraints while providing comprehensive memory isolation for ISO 26262 compliance.}

\vspace{0.5cm}
\textbf{Keywords:} ARM Cortex-M4, MPU, Automotive ECU, Performance Analysis, STM32F446, ISO 26262

\end{abstract}

This thesis presents experimental analysis of ARM Cortex-M4 MPU performance in automotive ECU environments, providing definitive quantification of context switching overhead through cycle-accurate measurements.

\section{Key Findings}

Experimental study of MPU region allocation performance establishes:

\begin{itemize}
    \item \keyresult{MPU Region Allocation: 990 ± 4 cycles (5.500 ± 0.022 μs)}
    \item \measurement{Baseline Performance: 130 ± 2 cycles (0.722 ± 0.011 μs)}
    \item \keyresult{Performance Overhead: 7.6× factor (860 cycles difference)}
    \item \measurement{Automotive System Impact: <1\% for 2-task systems}
\end{itemize}

\section{Conclusions}

\keyresult{ARM Cortex-M4 MPU provides robust memory protection with deterministic 990-cycle initialization overhead}, enabling automotive industry to achieve simultaneous security and real-time performance. The measured 7.6× overhead factor establishes MPU as optimal solution for automotive ECUs with predictable timing suitable for safety-critical applications.

Results validate practical feasibility for production automotive systems, making MPU protection transparent while providing comprehensive memory isolation for ISO 26262 compliance.
