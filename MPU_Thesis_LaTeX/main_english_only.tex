\begin{abstract}
This thesis analyzes Memory Protection Unit (MPU) performance in ARM Cortex-M4 STM32F446 for automotive ECU applications. Using cycle-accurate DWT measurements, we characterize MPU overhead in context switching, IPC, and memory operations with a custom Rust RTOS.

Key findings show MPU introduces 25\% context switching overhead and 32\% IPC overhead. However, optimization techniques including lazy reconfiguration and region caching reduce combined overhead to 8-10\%. The research validates MPU compatibility with automotive real-time constraints across ECU categories while supporting ISO 26262 functional safety requirements.

Results demonstrate that optimized MPU protection maintains real-time performance while providing essential memory isolation for automotive safety standards, enabling simultaneous achievement of high safety integrity (ASIL C/D) and real-time performance requirements.

\textbf{Keywords:} ARM Cortex-M4, Memory Protection Unit, Automotive ECU, Real-time Systems, Performance Analysis
\end{abstract}
